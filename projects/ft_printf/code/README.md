# ft_printf
## Description
The aim of this project is to replicate the functionality of the `<stdlib.h>` function `printf()`. This involves the introduction of a new concept in c programming: variadic arguments, and the `<stdarg.h>` library, with it's associated macros.
The project tree consists of one header file: `includes/ft_printf.h` and several .c files containing the constituent functions in the `srcs` directory.
## Instructions
The associated binaries and object files are produced by using the `make` command, which executes the compilation script contained in the `Makefile`.
## Resources
The main resources used were the two man pages for `printf` and `stdarg`, which describe the functioning of the `printf` function, and the various macros used to access variable arguments, respectively.
